# Decisões do projeto

## 06/10/2026

- A hospedagem segue a especificação: frontend e API no Render; PostgreSQL e Storage no Supabase.
- A data do acontecimento permanece uma string `YYYY-MM-DD` em todas as camadas. Instantes técnicos usam UTC.
- Os logos enviados são marcas das equipes por modalidade. Nenhuma marca de torneio foi criada ou baixada.
- A grafia sem acento presente no logo OBR foi preservada por integridade do arquivo original.
- O cartão de Simulações e Testes foi preservado somente nos originais e não é importado pela aplicação pública.
- O texto digitado por integrantes não é modificado. A plataforma, os dados de demonstração e a documentação não produzem emojis.
- O interior do diário usa papel claro sobre uma capa escura para manter a direção das referências e a legibilidade.
- Sem credenciais, a validação local cobre compilação e interface. Persistência em produção exige as variáveis descritas no manual.
